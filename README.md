# Typographic Arena Survival

Open `index.html` in a browser, or serve this directory with a static HTTP server. The page loads Matter.js from jsDelivr, so an internet connection is required.

Defend the cyan `[ CORE ]` from red enemy characters. Click or press Space to start. Keep clicking near incoming enemies to blast them away; the blast recharges every 1.5 seconds. The green glyphs form a movable barricade. The opening waves are gentle, then spawn more enemies as you survive. When integrity reaches zero, click or press Space to retry.
