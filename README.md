# Typographic Arena Survival

Open `index.html` in a browser, or serve this directory with a static HTTP server. The page loads Matter.js from jsDelivr, so an internet connection is required.

Defend the cyan `[ CORE ]` from red enemy characters. Click anywhere on the canvas to blast nearby bodies away; the blast recharges in 1.5 seconds. The green glyphs form a movable barricade. Survive as long as you can before integrity reaches zero, then reload the page to play again.
